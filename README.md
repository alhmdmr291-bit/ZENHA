# ZENHA

## المشروع
- `customer/` تطبيق الزبون.
- `admin/` لوحة إدارة منفصلة.
- `manifest.json` إعدادات PWA.
- `icon-192.svg` أيقونة التطبيق.
- `sw.js` Service Worker.

## ملاحظة مهمة
هذه النسخة هي الهيكل الأول للتطبيق، والمنتجات محفوظة محليًا في المتصفح. الخطوة التالية هي ربط تطبيق الزبون ولوحة الإدارة بقاعدة بيانات حقيقية، حتى تظهر المنتجات التي يضيفها المدير للزبائن على أجهزتهم.
